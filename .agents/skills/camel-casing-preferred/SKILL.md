# Prefer camelCase filenames

- Use camelCase for files that do not contain React components or classes
- Use PascalCase only for React component files and class files
- Permit camelCase and PascalCase files inside the same feature or folder
- Permit files with different casing to import from each other
- Permit a folder to use mostly one case with only a few files in the other
